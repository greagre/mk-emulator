# mk-emulator — эмулятор семейства «Электроника»

Веб-эмулятор программируемых микрокалькуляторов на одном ядре RPN: Б3-34, МК-51, МК-61.

## Что внутри

- `index.html` — сам эмулятор: корпус, клавиатура, регистры, режимы АВТ/ПРГ
- `core.js` — ядро RPN без DOM (чистая логика, тестируемая отдельно)
- `core-fix.js` — правки ядра после тестов
- `profiles.js` — профили моделей (Б3-34, МК-51, МК-61)
- `ui.js` — отрисовка корпуса и клавиатуры, привязка событий
- `layout.css` — оформление
- `shelf.js` — библиотека программ
- `convert.js` — импорт программ из файлов (JSON / TXT)
- `lang.js`, `lang.html` — МК-Алго: язык программирования текстом
- `decoder.js`, `b3-decode.html` — декодер кода в текст
- `algo.html`, `algo-v7.html`, `algo-v8.html` — редактор алгоритмов
- `catalog.html` — каталог программ
- `import.html`, `import-tests.html` — импорт и его тесты
- `tests.html` — проверка ядра (12 эталонов)
- `pack.html` — сборка автономного офлайн-файла `mk-offline.html`
- `programs/` — библиотека программ и `_catalog.json` (704 записи)
- `archive/`, `tools/`, `publish.cjs` — служебное

## Локальный запуск

Открывать `index.html` нужно **по адресу `file://`** в браузере, а не через файловый
менеджер (он отдаёт `content://`, и Chrome не подгружает соседние `core.js`, `ui.js`,
`layout.css` — получается голая разметка). Для полной автономности есть `pack.html`:
он собирает всё в один файл `mk-offline.html`.
