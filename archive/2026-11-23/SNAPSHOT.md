# Рабочая версия — 23 ноября 2026

**Состояние зафиксировано на коммите `18cb7de`** (мост «МК-Алго → эмулятор»).

## Что в этой версии работает

| Что | Проверено |
|:---|:---|
| Ядро Б3-34: стек, регистры, условные переходы | да |
| Профили моделей (`profiles.js`) | да |
| Тесты ядра — 14 кейсов | да |
| Библиотека программ + мост `takeBridge()` | да |
| МК-Алго: компилятор, листинг, лента вывода | да |
| Параметры не сбрасываются при пересборке | да |
| Передача программы «В эмулятор» | да |
| `7! = 5040`, `3! = 6`, `0! = 1` | да |

## Чего ещё нет

- кнопки возврата из эмулятора на страницу языка;
- запоминания введённых параметров между перезагрузками страницы.

## Как восстановить целиком

- скачать архив этой версии: https://github.com/greagre/mk-emulator/archive/18cb7de.zip
- посмотреть файлы: https://github.com/greagre/mk-emulator/tree/18cb7de

## Как восстановить один файл

1. Открыть нужный файл по ссылке `https://github.com/greagre/mk-emulator/blob/18cb7de/ИМЯ`
2. Нажать «Raw», скопировать всё содержимое
3. Вставить в текущий файл и сохранить (или попросить меня записать)

Коммит неизменяем: даже если `main` сломается десять раз подряд, `18cb7de` останется таким же.
